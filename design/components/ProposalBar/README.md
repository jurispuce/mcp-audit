ProposalBar appears at the top of a screen whenever AI has written proposals that nobody has reviewed yet.

It states how many proposals there are and which action produced them, and offers Review and Accept all. Review opens the list of proposed items as ItemCards in the proposed state, each with Accept, Edit and Reject.

The bar uses the `ai` tokens and a dashed border, the same signal as proposed cards and the AI button. It disappears when the last proposal is accepted or rejected. Findings can be accepted in bulk, but approving them into conclusions is always a separate, human step.
