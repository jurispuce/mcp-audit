Criticality shows high, medium or low as filled bars plus the word.

Use it on planned evidence, engagement requirements and risks. It is deliberately not coloured: colour is reserved for findings and evidence state, so a high-criticality item with good evidence does not look alarming.

Classes: `au-crit au-crit--high`, `au-crit--medium`, `au-crit--low`. Keep the word; the bars alone are not enough for a screen reader.
