PhaseChecklist is the engagement home screen: the eight audit phases as one list with progress and a single next step.

- A phase is **done** (filled `ok` dot with a check), **current** (`accent-soft` row with a progress bar) or **to do** (numbered outline dot).
- Each row shows one fact on the right: a count, not a percentage, wherever a count exists.
- Tapping a row goes to that phase's destination in the navigation. Phases are guidance: nothing is locked, and an auditor can open any row at any time.
- Under the list sits one primary button named after the next step, for example "Continue: extract internal requirements".

You provide the state and the one-line fact for each phase.
