# Prototype

`audit-prototype.html` is a self-contained page. Open it in a browser; it needs no server. Data is kept in that browser's local storage only.

- "Load sample engagement" on Home fills in an engagement so every screen has content.
- AI buttons are simulated: they invent plausible proposals so the review steps can be tried.
- "Log a gap" and "Test notes" exist only in the prototype.

What each screen must do in the real app, and what the prototype simplified, is in `docs/workflow-and-screens.md`.
