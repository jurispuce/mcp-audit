## What

See and fix which requirements are in which events.

## Acceptance criteria

- [ ] Summary of covered versus total, a filter for uncovered only, and requirement search
- [ ] Per requirement: pills for its events (open the event, remove from event) and "+ Add to event" with a searchable event list
- [ ] "Create a new event" from the picker pre-links the requirement and opens the event for editing
- [ ] A requirement can be in several events; uncovered requirements are listed first
