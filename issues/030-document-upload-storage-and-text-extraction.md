## What

Take in auditee documents with no friction.

## Acceptance criteria

- [ ] Upload one or many files in one action with no title or kind required
- [ ] Files stored once under their SHA-256 hash; duplicates detected
- [ ] Text extracted for PDF, DOCX and plain text and indexed for search
- [ ] Title, kind, version and approval date editable afterwards in the list
- [ ] A document can exist in state "mentioned" with no file
