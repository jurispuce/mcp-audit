## What

Let a user create a token that identifies them to the MCP endpoint.

## Acceptance criteria

- [ ] A user can create, name and revoke tokens in Settings
- [ ] Tokens are stored hashed and shown once
- [ ] A request with a valid token resolves to that user for authorship
